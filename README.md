# Velocity Auto Clicker

[Türkçe](README.tr.md)

Windows auto-clicker. Current version: **1.0.2**.

This repository publishes the installer only. Source code is not included.

## Download

Download **[VelocityAutoClicker.Setup.exe](https://github.com/TheWorkstyler/VelocityAutoClicker/releases/latest)** from [Releases](https://github.com/TheWorkstyler/VelocityAutoClicker/releases), or the `VelocityAutoClicker.Setup.exe` file in this repository.

## Install

1. Run `VelocityAutoClicker.Setup.exe`.
2. Choose **Next**, then confirm the install folder.
3. **Create desktop shortcut** and **Create taskbar shortcut** are checked by default. Uncheck any shortcut you do not want.
4. Choose **Install**.

Default location: `%LocalAppData%\Programs\VelocityAutoClicker`

## Uninstall

Use **Settings → Apps** and remove **Velocity Auto Clicker**, or run:

`VelocityAutoClicker.Setup.exe /uninstall`
