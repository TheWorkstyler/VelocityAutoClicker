# Velocity Auto Clicker

[English](README.md)

Windows otomatik tıklayıcı. Güncel sürüm: **1.0.4**.

Bu depoda yalnızca kurulum dosyası yayınlanır. Kaynak kod paylaşılmaz.

## İndirme

[Releases](https://github.com/TheWorkstyler/VelocityAutoClicker/releases) sayfasından **[VelocityAutoClicker.Setup.exe](https://github.com/TheWorkstyler/VelocityAutoClicker/releases/latest)** dosyasını indirin.

## Kurulum

1. `VelocityAutoClicker.Setup.exe` dosyasını çalıştırın.
2. **İleri** deyip kurulum klasörünü onaylayın.
3. **Masaüstünde kısayol oluştur** ve **Görev çubuğunda kısayol oluştur** kutuları varsayılan olarak işaretlidir. İstemediğiniz kısayolun işaretini kaldırın.
4. **Kur** ile yükleyin.

Varsayılan konum: `%LocalAppData%\Programs\VelocityAutoClicker`

## Kaldırma

**Ayarlar → Uygulamalar** listesinden **Velocity Auto Clicker** öğesini kaldırın, veya şu komutu kullanın:

`VelocityAutoClicker.Setup.exe /uninstall`
